# Template Variables Reference

This document lists all placeholder variables used in the template files. These are automatically replaced by the `init.sh` script during initialization.

## Project-Level Variables

| Variable | Description | Example | Used In |
|----------|-------------|---------|---------|
| `{{PROJECT_NAME}}` | Project display name | `My Awesome App` | root CLAUDE.md, common-rules.md |
| `{{PROJECT_SLUG}}` | Project identifier (kebab-case) | `my-awesome-app` | project-config.md, cost tags |
| `{{PROJECT_DESCRIPTION}}` | One-line project description | `A modern task management platform` | root CLAUDE.md |

## Monorepo-Level Variables

| Variable | Description | Generated By | Used In |
|----------|-------------|--------------|---------|
| `{{SUBPROJECT_TABLE}}` | Markdown table of sub-projects | Auto-generated from sub-project list | root CLAUDE.md |
| `{{MONOREPO_STRUCTURE}}` | ASCII directory tree | Auto-generated from sub-project list | common-rules.md |

### SUBPROJECT_TABLE Format

```markdown
| Sub-project | Path | Description |
|-------------|------|-------------|
| Backend | `backend/` | Python + FastAPI |
| Frontend | `frontend/` | React + TypeScript |
| Infrastructure | `infra/` | AWS CDK |
```

### MONOREPO_STRUCTURE Format

```
my-awesome-app/                  # Monorepo root
├── .claude/                     # Root: common specs
│   ├── CLAUDE.md                # Global entry point
│   └── rules/
│       ├── common.md            # Cross-project rules
│       └── principles/          # Cross-preset engineering principles
├── backend/                     # Backend (Python + FastAPI)
├── frontend/                    # Frontend (React + TypeScript)
├── infra/                       # Infrastructure (AWS CDK)
├── .gitignore
└── README.md
```

| Variable | Default | Description |
|----------|---------|-------------|
| `{{COVERAGE_MIN}}` | `85` | Minimum test coverage % |

> **Note**: aws-cdk preset hardcodes `pnpm` in templates. Unlike react-typescript, the CDK ecosystem's toolchain commands (`pnpm cdk synth`, `pnpm exec`, GitHub Actions `pnpm/action-setup`) are tightly coupled to the specific package manager, making simple text substitution unreliable.

## Variable Syntax

### Standard Variables: `{{VARIABLE_NAME}}`

Standard variables use double curly braces with UPPER_SNAKE_CASE names.

- Variable names are UPPER_SNAKE_CASE
- Variables are replaced by `sed` (init.sh) or AI (init-context command) during initialization
- Unreplaced variables remain as-is in the output (useful for manual customization)

> **仅用于 generic preset 模板**。内置 preset（python-fastapi 等）不使用此占位符。

## Adding Custom Variables

If you need additional variables for a custom preset:

1. Define them in your `preset.yaml` under the `variables` section
2. Use `{{YOUR_VARIABLE}}` in your template files
3. Update `init.sh` to prompt for and replace the new variables
