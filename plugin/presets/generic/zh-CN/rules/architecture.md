### 通用依赖规则

- 依赖方向只能向下（单向依赖）
- 禁止循环依赖
- 高层模块不应依赖低层模块的实现细节
- 依赖抽象（接口/协议）而非具体实现

### 通用隔离规则

| 规则 | 说明 |
|------|------|
| **模块间接口通信** | 模块间通过明确接口通信，隐藏内部实现 |
| **显式导出** | 只导出公开 API，禁止通配符导出 |
| **单一职责** | 每个模块/组件只负责单一职责 |
| **关注点分离** | 业务逻辑与技术基础设施分离 |
